# 原生书源真机验证步骤与记录

日期：2026-11-08。对应 P1-06/P1-07、D02/D03/D10。已有离线示例与两份本地联网源的用户通过反馈；本表只列仍需补充的设备证据。不得将模拟器成功代替真机性能或硬终止验收。

## 准备

1. 安装本轮 GitHub CI 生成的 IPA，记录提交、App 版本、设备型号、iOS 完整版本、电量/低电量模式、网络类型。保留现有本地书源即可，不上传网站专用源或正文。
2. 打开「设置 → 其他设置 → 书源协议实验室」。离线示例先执行四项操作一次，作为恢复基线。
3. 资源测量需要连接 macOS 的 Xcode Instruments，记录 App 与相关 WebContent 进程总内存、CPU、能耗；只有 Windows/iPhone 时仍可记录 UI、取消、前后台与恢复现象，但内存/能耗栏保留“未测”。

故障源没有 search 入口；选择 content 并使用输入 `{"book":{"id":"fixture-book"},"chapter":{"id":"ch-1"}}`。这些故障操作不访问 metadata 中的 loopback 地址，真机不需要连接本地 fixture 服务。

## 操作与证据

| 场景 | 步骤 | 应记录的结果 |
| --- | --- | --- |
| 冷启动与重复运行 | 杀掉 App 后启动，运行离线 search；再连续执行十次四项操作 | 每次开始至结果的时间、失败码、首次与后续差异；没有 Instruments 时标注手动计时 |
| 无穷 Promise | 导入 `protocols/source-v1/fixtures/runtime-faults/never-settles.source.js`，检查元数据，运行其 content | 原生 deadline 是否结束操作、UI 是否可交互；随后切回离线源的四项操作是否正常 |
| 用户取消 | 运行上面的等待源后点取消；再切回离线源 | 是否只出现一个终态、是否还能开始新操作；原生网络取消另由 CI fixture 验证 |
| 前后台 | 普通离线操作和等待操作分别切后台再回来；各重复三次 | 是否重复结算、界面卡死或恢复后无法执行；记录后台停留时长 |
| 同步无限循环 | 单独一次使用 `runtime-faults/infinite-computation.source.js` 的 content；不要放入自动批量流程 | UI、deadline、WebContent CPU、总内存、新页面是否受牵连；必要时手动退出 App，记录是否必须重启才能恢复 |
| 内容进程异常 | 有 macOS 调试设备时做受控 WebContent 进程终止；仅 Windows 环境此项保留待测 | RUNTIME_TERMINATED 是否可见、旧回调是否失效、下一正常操作能否恢复 |
| 持续运行资源 | 同一普通源重复运行并在成功/取消后观察 30 秒，再重复三轮 | App + WebContent 总资源趋势；系统缓存不能误记为泄漏，需比较稳定阶段 |

无限循环源故意会持续占用内容进程。原生显示 TIMEOUT 仅证明等待结束，不证明 JS 已停止；该场景务必记录资源与后续正常源的影响，不能只看弹出的错误。

## P2/P3 阅读与编辑的设备复核

以下通过常规 iPhone/iPad 操作即可记录，不需要上传私人书源或正文。测试时标注本轮 IPA 的 SHA；不要用上一版协议实验室成功代替新入口验收。

| 场景 | 操作 | 通过条件/记录 |
| --- | --- | --- |
| 安装与文件分享 | 「原生书源阅读」添加离线示例，检查并保存；在设置导出 .source.js，经文件 App 导入第二份 | 新安装独立存在；源码可读；没有配置、书架或正文拼入文件；检查时不执行未知源 |
| 常规阅读 | 搜索任意关键词、加入书架、加载目录、打开第一章、改字号、返回详情继续读 | 正文可读；书架/目录/进度没有串到另一安装；重复标题按 ID 区分 |
| 离线与重启 | 下载后退出 App；开启飞行模式，重开并选择仅离线阅读 | 书架、目录、已下载正文可用；恢复位置；未下载章明确提示，没有无限加载 |
| 切章与取消 | 使用受控多章源快速前后切章；读取/下载期间取消后再打开 | 旧结果不能跳回前章；已完成下载保留；取消后能继续使用 |
| 大字号与布局 | 系统最大辅助字号、深色、横屏、iPad 分屏分别打开阅读和设置 | 无横向溢出；标题/按钮可辨识；触控至少 44pt；底栏不压 Home Indicator |
| 键盘 | 聚焦地址、源码、数值设置；拖动表单、点击收起、提交搜索 | 输入仍可见，完成动作可退出键盘；无底栏遮挡输入 |
| 未保存保护 | 编辑后下拉弹窗、点关闭、在编辑中获取上游候选 | 不静默丢失文本；放弃有明确确认；取消保持草稿；背景不能被误操作 |
| 更新与回滚 | 修改源标题及版本、检查、审阅网站范围、保存；从历史恢复 | 同安装 ID 保留；当前书架不丢；源码历史可见；回滚明确不恢复 state |
| 旧编辑器冲突 | 两次读取同一安装、先保存其中一个、再提交旧候选 | 旧摘要被拒绝，不能覆盖新版本；重新读取后可再次审阅 |
| 权限与另存 | 候选新增 origin 或改 publisher ID | 新 origin 显示；必须手动保存；不同 ID 只可独立安装，不接管旧书籍 |
| 配置变化 | 改设置后重开书籍，尝试旧目录在线阅读，然后刷新目录 | 在线不混用旧目录与新配置；离线旧缓存有说明；配置不导出到源码 |
| 无障碍 | VoiceOver 逐项浏览添加、取消、字号、前后章及错误恢复 | 控件有可理解标签，阅读顺序正确，错误入口可操作 |
