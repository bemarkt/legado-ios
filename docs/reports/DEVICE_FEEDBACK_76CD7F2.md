## 修复范围

1. **失败响应可检查。** 目录或正文为空时，将供规则解析的响应文本与该次 operation UUID、准确书源摘要关联。详情显示最终地址、Content-Type、HTTP 状态、原始字节数及文本；HTML 作为普通文字展示，不执行。最近 8 份、每份最多 64 KiB UTF-8、15 分钟内可查询，仅留内存；清除诊断同时删除。普通 JSON 报告保持不含地址、网页文本及凭据。内容可能包含网站个人信息，仅供本机查看。
2. **验证回到失败页。** 从响应详情“打开此页面验证”，按当前书源权限校验最终 URL，以当前会话和书源 UA 重新 GET 该页面。保存登录后回到详情刷新目录。不会自动反复访问、放宽书源访问域，也不会重放响应头、旧 Cookie 或 POST。此入口不承诺所有网站验证都只依赖 Cookie。
3. **离线选择按书籍持久化。** 迁移书仅首次默认离线；明确选择优先于初始化默认值。存储键使用本地书籍身份，不因网站登录改变。模型串行完成写入，关闭页面不取消；载入时等待待写入选择，离线时不自动请求目录。
4. **源码弹窗携带完整内容。** 设置、历史版本与诊断源码入口按 item 传递源码快照，避免分开修改 Boolean 和字符串导致第一次为空。每次打开有独立编辑状态。
5. **相关兼容修正。** Legado 提取层已有 5000 项单页上限，目录服务过去固定 1000。现按 provider 限额校验；原生协议仍为 1000，未改变其合同。这是额外发现，不能解释 209 字节响应。

## 真机复测

1. 覆盖安装匹配本次提交的 IPA，保留旧数据；进入原来的旧书，关闭“仅使用离线章节”，返回书架，再打开，确认仍关闭。结束 App 后重开再确认。另一本书的选择应互不影响。
2. 在书源设置打开“查看或修改源码”，首次即可看到完整 JSON；关闭重开、打开历史版本，内容应与选中版本一致。原生 JS 入口也检查一次。
3. 刷新失败目录后直接点“查看失败响应”，确认地址、202、209 字节和响应文本。若为验证页，点“打开此页面验证”，完成网页交互并“保存登录”，返回刷新。记录成功或新的响应，不把“保存 Cookie”当成网站确认登录。
4. 若仍失败，在本机对照实际页面和 ruleToc.chapterList。普通诊断导出继续可分享，但不含上述正文；如提供响应内容，先检查其中是否有个人信息。已缓存目录、下载、阅读进度仍应可离线使用。
5. 在诊断列表确认对应记录可查看详情；清除诊断后原详情应提示已过期；旧版导出没有正文时明确显示未保留。
