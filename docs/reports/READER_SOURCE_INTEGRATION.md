# 成熟阅读器与新书源领域接入

日期：2026-11-09。此记录延续产品接线核对；实现、自动化及设备验收分别记录。

## 章节访问接口

`ReaderChapterAccess` 让阅读模型按稳定章节 ID 请求内容。`SourceReaderChapterAccess` 固定本次目录和本地书籍身份，在线使用 SourceLibraryService、当前网站会话和 SourceArchive；离线直接读取本地副本，不初始化书源引擎或网站凭据。正文快照保留规范化 ChapterDocument 及实际缓存来源。

同章并发消费者共享工作；取消一个消费者不取消其他消费者，最后一个取消或关闭会话会取消底层任务。显式刷新替代先前普通读取，旧任务 UUID 不能完成新请求；缓存写入继续受目录、网站会话、取消与数据库 CAS 校验约束。

成熟 ReaderViewModel 的当前章、相邻章、连续滚动和下一章朗读已增加接口路径；原 Legado、TXT、EPUB 路径保留。朗读预取增加导航代次和取消检查，防止离开后交付旧正文。当前只有接口与模型接线，尚无用户入口使用它。

新增核心回归覆盖缓存来源、HTML 文档保留、离线不创建 provider、跨安装隔离、网站会话与目录失效、合并请求、独立取消、刷新替代及关闭后迟到响应。模型回归覆盖四个读取入口、刷新/重试、导航与取消、离线错误及旧换源隔离。038d418 / 42609230620 的 526 项核心和 App 编译通过，82 项页面模型中一项断言遗漏 localizedDescription 的错误码前缀；已修正比较标准错误描述，待复验。规则与恢复步骤因前项失败被跳过。Source Protocol 42609230554 成功。

## 后续接入边界

### 本地阅读状态实现（待 GitHub 验证）

新增 SourceArchive 读写接口，以完整 SourceBookKey 为范围保存阅读偏好、书签和阅读会话。偏好按单字段在事务内更新，避免不同窗口从旧快照覆盖彼此。书签使用稳定章节锚点与 revision 比较更新；迁移笔记作为保留的原始记录，由可编辑覆盖记录及删除标记呈现，不改写恢复材料。

阅读 checkpoint 使用会话 UUID、递增序号和累计毫秒数；重复同一 checkpoint 不多计时间，新窗口使旧窗口进度写入失效。时长记录和锚点在同一 SQLite 事务提交，失败后可重试。排序使用日期，写入先后使用会话/序号，不依赖系统时间单调递增。未接 UI，也未把这些接口写成实际历史/统计功能已完成；跨日统计、活动生命周期与成熟阅读器存储接线仍需完成。

新增测试覆盖相同书名作者跨安装隔离、两个数据库连接更新不同偏好、书签冲突/删除后旧编辑拒绝、重开、checkpoint 重放/旧窗口拒绝、注入锚点写入失败后全部回滚，以及迁移笔记编辑/删除/重试采用保持恢复证据。网站凭据和旧 BookLibraryModel 不参与这些本地写入。

1. 按稳定 BookKey 持久化偏好、阅读活动、书签和进度，不能用旧模型按书名/作者合并新域数据。
2. 让渲染后的正文与锚点坐标一致，保留规范化 heading/mark；净化和内容修订后验证位置恢复。
3. 将 ReaderView 的存储行为抽出，再连接新书籍详情；保留诊断、网站验证与离线恢复入口。
4. 完成实际 iOS 链路后再提供匹配 IPA。主入口、旧数据库、EPUB 原排版仍按原计划验收条件处理。
