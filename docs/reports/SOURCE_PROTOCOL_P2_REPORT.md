初版：2026-11-08；更新：2026-11-09（Asia/Hong_Kong）。状态：实验实现已接入；G1 真机资源与故障恢复、G2 完整设备验收仍开放。此报告同时记录已提前实现的 P3 安装、编辑与更新范围，不表示 P2–P6 全部完成。

## 可操作的路径

App → 设置 → 其他设置 → 原生书源阅读。添加文件、粘贴或下载 HTTPS 原始文本 → 静态检查 → 审阅名称/版本/访问网站 → 保存安装 → 搜索 → 加入书架 → 书籍详情/目录 → 章节阅读/翻章 → 下载 → 离线重新打开。原协议实验室继续用于单次 JSON 调试，未绑定安装，不能使用持久化 storage。

书源设置中可以编辑、导出 `.source.js`、检查原始地址更新和审阅历史版本。源文件始终自包含，导出只含当前源码；数据库、配置、Cookie、书架和正文不会拼入导出文件。原始地址下载限制 HTTPS、UTF-8、2 MiB 和同 origin 重定向，暂不支持跳转至不同域名的下载短链。

`SourceArchive` 的源码、活动记录、历史和可选配置重置同处 SQLite 事务，避免当前范围内跨文件/数据库的双写。没有文件指针切换。安装摘要改变才新增历史；旧编辑器不能覆盖新版本，不能更换 publisher ID 来继承旧书籍。已有 provider 持有不可变快照，新 provider 读取当前安装。换源码/配置后旧目录不能直接用于新的在线读取，界面要求刷新；显式离线仍可读旧缓存并给出提示。

源状态与源码回滚分开：源码回滚不撤销已经提交的 state。无法确认兼容的候选必须另存独立安装。此约束也显示在编辑界面，不能以回滚按钮存在推断状态回滚已实现。

数据库写入通过原生提交门禁与操作终态线性化：终态之前已提交数据保留；终态或较新操作使门禁失效后，排队/迟到结果拒绝提交。此保证不表示能硬终止同步 JavaScript，也不撤销远端 HTTP 副作用。

## 移动端设计检查

依据用户补充的 mobile-design-system，采用原生 NavigationStack/List/Form/sheet/safeAreaInset：不侵占系统安全区，不自建返回手势；阅读底栏按钮至少 44pt，间距 12pt；编辑器支持收起键盘，列表拖动收起；未保存导入/编辑禁止手势静默关闭，关闭和替换草稿需确认；系统色与文本支持深色和 Dynamic Type；弱网与离线错误提供重试或明确状态。

SwiftUI 原生组件承担系统安全区、键盘和模态层背景阻断。该技能附带 linter 只识别 Web/React 代码，本报告不把它对 SwiftUI 的空结果计作通过。模拟器截图测试覆盖 390×844、超大辅助字号深色和 1024×768；真实键盘交互、VoiceOver、iPad 分屏和手势必须设备复核。
