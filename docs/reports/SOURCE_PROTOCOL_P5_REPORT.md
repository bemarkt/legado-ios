日期：2026-11-09。状态：实现中，自动化未完成；没有切换默认入口或覆盖旧数据库。当前执行顺序维护在实施计划第 13 节。

## 版本 1 映射规则

每次迁移先生成私有恢复副本，再在独立 SourceArchive 中建立草稿。恢复材料含原数据库、外部文件、逐表数量、逐文件字节数和 SHA-256，可能含登录资料；它不属于可分享书源或普通诊断导出。原库以只读连接备份，提交过的 WAL 数据通过 SQLite online backup 纳入。

| 数据 | 新结构与关联方法 | 无法转换时 |
| --- | --- | --- |
| book_sources | 保留单条原始 JSON、未知字段和摘要；确定性安装 ID；保留启用/分组元数据 | 非文本源、损坏 JSON、键与 payload 不符列入待处理，原记录仍在恢复库 |
| books | 来源 URL 精确关联安装；书籍请求完整保留查询参数；生成 provider 可读的持久引用；保留排序和分组 | 本地 TXT/EPUB 留在原功能；缺源/无效引用保留待处理 |
| chapters | 只在原书籍下核对 URL、数据库索引及 payload；卷转为 volume；重复标题不参与章节身份 | 重复索引、重复地址、损坏行不拼成看似完整的目录 |
| 章节 JSON 缓存 | bookURL/chapterURL 精确定位；核对 sourceID；写入带身份和 provenance 的离线正文 | 重复候选、错源、补充正文、损坏或孤立缓存保留并分类 |
| 阅读位置 | 同一旧章节索引；已知旧正文处理结果与新规范化正文一致时使用 UTF-16 位置 | 字符边界不符、正文变化、缓存缺失或替换规则未知时保留原位置，提示重新定位 |
| bookmarks | 旧模型没有 bookURL；仅在书名和作者同时精确匹配且唯一时关联书籍，再使用旧章节索引；保留笔记、原文、时间 | 不按相同章节标题猜测；不确定时保留全文待处理；唯一引文可在确定章节内恢复位置 |
| caches 普通变量 | 精确识别 v_源ID_变量键，映射到单独账号的 scoped state；有期限的状态保守保留 | 来源前缀有歧义、超限、未知键不导入普通状态 |
| Cookie/登录字段 | 私有恢复副本保留；报告只记录需要重新登录 | 不把来源不明确的凭据分发到访客或多个新账号 |
| 其他表 | 全部计数和原数据库逐字节保留；现有本地/RSS/规则/TTS/记录页面继续提供产品访问 | 不以备份存在宣称这些功能已全部接入新核心；逐项替换和旧路径退出仍需验收 |
| 外部配置、TXT/EPUB、defaults | 明确选择 App 所有的数据路径，保存原文件/设置 | 不收集任意系统 defaults 或未授权个人目录；缺文件单独登记 |

迁移不执行书源或替换规则中的 JavaScript。已明确捕获的普通替换规则可以重现旧阅读文本；带 JS 的替换规则保持待核对。来源安装和访问范围仍需产品审阅后采用。

## 可恢复边界

- 快照只有完整检查通过才发布 manifest.json；失败的尝试目录保留。已有完成快照在重试时重新校验，不覆盖原恢复材料。
- 映射草稿使用 SQLite 进程锁；原始快照、映射版本和摘要构成任务身份。失败不发布 report.json，重新运行创建新的草稿；已完成任务重新校验并返回同一报告。
- 可写阅读预览始终从校验过的草稿复制，不能直接打开不可变恢复库触发旧版 schema/journal 修改。
- 自动化检查点覆盖书源、书架、正文/状态、发布前和发布后。抛异常的检查点不等于已验证真实 SIGKILL、空间耗尽或设备后台终止。
- 采用迁移结果后的新笔记和进度不在旧快照中；没有双向同步时，恢复旧库不等于无损降级。
