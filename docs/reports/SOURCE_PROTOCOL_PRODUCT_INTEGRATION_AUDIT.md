## 已确认的入口

`App/LegadoApp.swift` 仍创建原有 SourceLibraryModel、BookLibraryModel、ReadingActivityModel、RSSLibraryModel、RuleSubscriptionModel，主界面是 `App/RootTabView.swift`。自有协议与独立 Legado provider 从 `App/Features/Settings/OtherSettingsView.swift` 的“原生书源阅读”进入，由 `App/SourceRuntime/NativeSourceLibraryView.swift` 持有单独的 NativeSourceLibrary。默认入口和旧库没有切换。

| 能力 | 当前接线 | 下一步与验收要求 |
| --- | --- | --- |
| 自有 JS / 旧 JSON 导入、源码、搜索、详情、目录、下载 | 新预览已接 SourceProvider / SourceArchive；旧主界面仍用原 SourceLibraryModel | 统一入口前明确安装身份、未知字段、重名和更新冲突策略，保留现有导入体验；新增两种格式都需覆盖文件和 URL 场景 |
| 网站登录、Cookie、封面、诊断 | 新预览已接撤销会话、Keychain、独立网页登录和共享 HTTP；本机失败响应可查看 | 继续实际网站 202 复测。不能把新域的登录凭据复制为另一个全局 CookieStore，也不能把登录状态用作书架分区 |
| 书架、分组、排序、用户元数据 | 新预览有持久书架与迁移排序；分组/批量操作仍在旧主界面 | 在稳定本地 BookKey 上接入现有书架行为，先比较保存、重排、删除和跨会话结果，不能靠导入后可阅读代替完整书架验收 |

| TTS / 净化 / 替换 / 阅读设置 | 原阅读器及配置入口仍在；新滚动预览未整合全部行为 | 通过规范化文本与阅读会话接入；规则开关前后内容修订与锚点解析需一致。TTS 设备播放仍需实际验收 |
| 深链接 / 外部打开 | LegadoApp.onOpenURL 仍走 EPUB / 旧书源 / 替换规则路径 | `.source.js` 外部打开应有独立路由和静态审阅，不能落到旧 JSON 解码；保留原 EPUB 与 legado URL 行为 |
